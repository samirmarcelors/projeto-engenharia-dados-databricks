# 🚀 Pipeline de Engenharia de Dados com Databricks

## 📌 Sobre o projeto

Projeto prático de Engenharia de Dados desenvolvido utilizando Databricks Free Edition, Python, PySpark, SQL e Delta Lake.

O objetivo é construir um pipeline ETL para processar dados fictícios de vendas de uma empresa.

## 🛠️ Tecnologias utilizadas

- Python
- Apache Spark
- PySpark
- SQL
- Delta Lake
- Databricks

## 🏗️ Arquitetura Medallion

O projeto utiliza três camadas:

### 🥉 Bronze
Armazenamento dos dados originais.

### 🥈 Silver
Limpeza, padronização e tratamento dos dados.

### 🥇 Gold
Preparação dos dados para análises e indicadores empresariais.

## 📊 Dados utilizados

- Clientes
- Produtos
- Vendedores
- Vendas

Os dados são fictícios e utilizados exclusivamente para fins educacionais.

## 📈 Indicadores desenvolvidos

- Faturamento por produto.
- Faturamento por vendedor.
- Faturamento por região.
- Quantidade de vendas.

## 🎯 Objetivo de aprendizagem

Desenvolver conhecimentos práticos em Engenharia de Dados, processamento distribuído, transformação de dados e arquitetura Lakehouse.
